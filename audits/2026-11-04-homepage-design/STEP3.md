# 第 3 项：区分筛选与搜索无结果

2026-11-04。第 3 项本地实现及验收完成；未实施第 4 项，未发布 QA / Production。

## 修改

- 有区域或友好度筛选时，提示“当前筛选下暂无地点”，不显示补充地点入口。
- 主操作清除区域和友好度筛选；存在关键词时明确标记“清除筛选，保留搜索”，并保留用户输入。
- 无筛选且关键词搜索无结果时，显示具体关键词，优先“清空搜索”，将“补充这个地点”改为次要描边按钮，并提示先检查全名、拼写或街道。
- 清除筛选/搜索后，焦点回到搜索框。补充入口继续使用原有流程，保留名称预填。
- 空列表且无关键词时不以“这间公寓”引导新增；提供搜索入口。
- 空状态按钮可换行，最小高度 44px；长关键词标题允许折行。

- PASS：npm run build:qa；git diff --check。

- PASS：搜索 Bukit 得到 2 条结果，叠加 Skudai 区域和“很顺畅”后无结果；点击“清除筛选，保留搜索”后区域恢复全部，关键词仍为 Bukit、恢复 2 条结果，焦点在搜索框。
- PASS：搜索合成名称 Audit Empty Place，无筛选时显示具体关键词、“清空搜索”和次要“补充这个地点”；手机截图检查通过。
- PASS：点击“补充这个地点”仅打开表单，名称预填 Audit Empty Place。未保存或提交，返回首页后点击“清空搜索”恢复列表和搜索焦点。
