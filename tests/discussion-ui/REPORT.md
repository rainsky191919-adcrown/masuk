# 司机讨论分页：本地实施与验证

日期：2026-11-04。结果：**PASS after auto-fix**。用户范围：修改、本地验证；不发布 QA。

## 已实现

- 地点卡片的讨论入口直接定位讨论；查看规则入口保持进入详情顶部。
- 帖子最多10个一页，置顶计入10个名额。先分类／排序再分页，分类带数量；采用固定ID作同时间排序的次级条件。超过10条才显示上下两处分页，首末按钮正确禁用。
- 每帖回复独立最多10条一页，按时间正序；显示当前范围、总数和页码，可跳最新。回复页与帖子页互不影响。删除／隐藏减少总数时钳制到最近有效页。
- 回复入口移到帖子操作行，输入区明确对应帖子标题。长正文／长回复按需展开；举报、删除和置顶等操作收进更多。
- 当前应用会话内按账号和地点保留分类、排序、帖子页、回复页、展开状态、未提交草稿和滚动位置；不向其他账号复用草稿，不写入额外的浏览器持久存储。
- 发布成功后定位实际内容所在页并高亮。新帖能定位到置顶帖之后的实际页；回复能在并发追加情况下找到自己回复所在页。保存失败保留草稿。已保存而概览刷新失败时不误报为未保存。
- 周期性概览更新只提示有新内容，不自动重排正在读的列表；用户选择更新后载入。读取失败保留上一页内容并提供重试。翻页移动到相应标题并提供可读的加载／范围状态，按钮至少44px高。
- 共享模式改用新增只读 `masuk_discussion` RPC：概览只返回帖子数量／版本和已有反馈，帖子及回复按服务端 `LIMIT 10` 读取。帖子响应没有嵌套回复正文。保留旧 `feed` 接口兼容旧客户端，新页面不再调用它。

## 后端边界

新增迁移文件：`supabase/migrations/20261104090000_discussion_pagination.sql`。只新增索引、私有只读函数及公开 SECURITY INVOKER 包装；固定 search_path、显式收紧函数执行权限，保持现有表 RLS 和写入接口。隐藏帖子、隐藏回复、隐藏父帖下回复不进入结果。本人帮助／举报状态仅返回当前用户标志，不返回其他举报人。

**该迁移仅在本地随机命名、无网络的临时 PostgreSQL 容器中执行；没有应用到 QA 或 Production。未来发布新版前，须先在获授权的对应环境部署该增量迁移，不能只上传前端或重跑初始化。**
