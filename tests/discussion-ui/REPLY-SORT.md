# 回复顺序选择：本地验证

2026-11-04。帖子回复区新增“最早回复优先／最新回复优先”选择。“看最新回复”现在切换为从新到旧第一页，每页最多10条；不是仅跳到旧排序的末页。默认最早优先以保留已有阅读行为。

排序按全部可见回复的时间及ID稳定排序后分页。本地模式与共享RPC使用同一语义；切换排序回到第一页，每帖独立记忆排序、页码和草稿。新回复成功后按当前顺序定位本人回复。排序读取失败保留原顺序与原页，重试恢复用户请求的顺序。
